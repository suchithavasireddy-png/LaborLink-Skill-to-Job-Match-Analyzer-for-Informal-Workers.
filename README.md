# LaborLink — Labour Marketplace Web Application

LaborLink is a full-stack web platform connecting skilled workers with employers across India. It includes a **Worker Portal**, **Recruiter Portal**, **Admin Dashboard**, in-app messaging, job recommendations, and Leaflet-based map view — all working together with zero external dependencies during demonstration.

---

## Quick Start — One-Click Launch

### 1. First-Time Setup (Run Once)

Double-click **`Setup_LaborLink.bat`** in the project folder.

This script will:
- Verify Node.js is installed
- Install all npm dependencies
- Compile and build the application

> **Node.js requirement:** If Node.js is missing, download it from [nodejs.org](https://nodejs.org) (v18 or higher), then run `Setup_LaborLink.bat` again.

---

### 2. Start the Application

Double-click **`Start_LaborLink.bat`** in the project folder.

The launcher will:
1. Ensure Node.js is accessible
2. Install dependencies if missing
3. Compile the backend server
4. Start the server on `http://localhost:3000`
5. Wait until the server is fully ready
6. Automatically open your default browser to the application

**Keep the black terminal window open** during your demonstration — it is the running server. Press any key in that window to gracefully stop LaborLink.

---

### 3. Stop the Application

Either:
- Press **any key** in the `Start_LaborLink.bat` window, OR
- Double-click **`Stop_LaborLink.bat`** to immediately release port 3000.

## Recommended Demonstration Flow

### Worker Portal
1. Click the **Worker** quick-fill button → Login
2. View the **Job Feed** with real-time skill filtering
3. Use the **Search/Filter** bar (by skill, location, experience)
4. Click **Map View** to see Leaflet markers for jobs across India
5. Bookmark a job with the ❤️ button
6. Click **Apply Now** on a job → confirm ₹50 UPI payment → "Applied" badge appears
7. Check **My Applications** tab to see application status
8. View **Notifications** bell for new messages

### Recruiter Portal
1. Click the **Recruiter** quick-fill button → Login
2. **Job Listings** tab — see all posted jobs with applicant counts
3. **Post New Job** tab — fill in details, click Save
4. **Browse Workers** tab — view available workers, click a card to open full profile
5. **Applicants** tab — accept or reject worker applications
6. Send a message to a worker from the Browse Workers modal

### Admin Dashboard
1. Click **Admin Login** link → use admin quick-fill button
2. View platform **Metrics**: total users, revenue, jobs, applications
3. See **Revenue Charts** (Recharts bar/pie graphs)
4. **Pending Jobs** section — approve or reject submitted jobs
5. **User Management** — view all users, suspend accounts, reset passwords
6. Click **Export CSV** to download all transactions

## Troubleshooting

### The browser does not open automatically
Open your browser manually and go to: **http://localhost:3000**

### "Node.js not found" error
1. Install Node.js from [nodejs.org](https://nodejs.org) (LTS version)
2. **Restart your computer** so the PATH is refreshed
3. Run `Setup_LaborLink.bat` again

### Port 3000 is already in use
Run `Stop_LaborLink.bat` first, then try `Start_LaborLink.bat` again.

### "npm install failed" or dependency errors
Ensure your machine has internet access for the first run. Run `Setup_LaborLink.bat` to reinstall.

### Server fails to compile or start
Check that `server.ts` and `package.json` have not been manually edited incorrectly. You can verify TypeScript with:
```
cd "c:\Users\vasir\OneDrive\Desktop\iip"
npx tsc --noEmit
```

### Data resets on every launch
LaborLink uses an in-memory database. All demo data is re-seeded automatically each time the server starts. This is expected behaviour for a demonstration project.

## Prerequisites

- **Node.js** v18 or higher (installed at `%LOCALAPPDATA%\Programs\nodejs` or system-wide)
- **Windows 10 / 11** (batch scripts)
- **Internet access** only for the first run (`npm install`)
- All subsequent runs work **fully offline** including maps (Leaflet tiles still need internet for satellite imagery, but markers and the job map function offline)

## Notes for the Teacher

- All user data, job listings, applications, messages, and transactions are pre-seeded with realistic Indian worker/employer profiles
- 60 job listings are auto-generated across 7 Indian cities
- The recommendation engine scores jobs by skill match, city proximity, and years of experience
- The ₹50 application fee is a simulated UPI transaction (no real payment gateway is used)
- The Gemini AI integration (`.env` key) is optional — all core features work without an API key
